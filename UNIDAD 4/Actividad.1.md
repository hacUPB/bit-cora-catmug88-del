# Actividad 1 - 2 - 3

Hay un ejericio de como utilizar open frameworks para crear una aplicacion de consola que muestra una serpiente de nodos que siguen la posición del mouse. Además estan unas funciones para agregar y quitar nodos de la lista. 

 En el ejercicio se crean unos nodos, cuya estructura es datos + puntero, por lo que apuntan a otro nodo. Además se utiliza una lista enlazada, que en esta unidad estamos aprendiendo de estructuras de datos y esta es una estructura generalizada, para entender el concepto de lista.
